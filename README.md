## 📌 About the Project

A full-stack real-time chat application where users can **send messages in their own language** and receivers see them **automatically translated** into their preferred language — powered by Google Translate API and WebSocket communication.

---

## ✨ Features

- 🌍 **Auto Language Translation** — Messages translated in real-time via Google Translate API (100+ languages)
- ⚡ **Real-Time Messaging** — Instant bidirectional communication using WebSocket (STOMP protocol)
- 🔐 **Secure Authentication** — JWT-based login/registration with Spring Security
- 👥 **Multi-User Chat Rooms** — Multiple users can join and chat simultaneously
- 📱 **Responsive UI** — Clean, mobile-friendly interface built with React.js
